# Inner Vault Landing Page

The standalone website for **Inner Vault**, built as a sibling of the other
Moving Truth app sites and designed around the app's own warm-metal, dark-stone visual
language.

The product is intentionally presented as pre-release. The site distinguishes approved
product direction from implemented and verified protection, and Robin approved its
public release on October 22, 2026.

Public address: `https://inner-vault.movingtruth.com`

## Local preview

Serve this directory with a static web server. For example:

```bash
python3 -m http.server 8088
```

Then open `http://127.0.0.1:8088`.
